# Authored document samples

These small English samples are original test material for Polaris and contain no remote resources.

- PDF: two pages, selectable source text and vector figures; Polaris currently renders pages and uses its existing OCR translation path.
- EPUB: two spine sections, local PNG figure, title and author.
- DOCX: paragraphs, local embedded image and a two-cell table; Polaris linearizes the table text.
- TXT: UTF-8 paragraphs long enough to check section navigation and saved progress.

They are fixtures for the pending Windows/Android acceptance run, not evidence that the Android runtime has passed.
