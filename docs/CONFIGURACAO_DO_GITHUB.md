# Campos de apresentação no GitHub

A página inicial, o histórico e a documentação já estão publicados. O rascunho de versão também foi criado, sem APK anexado.

A edição dos campos laterais **About / Sobre** retornou **HTTP 403 — Resource not accessible by integration**. A conta vinculada tem papel de administrador, mas a integração usada nesta tarefa não recebeu permissão para alterar configurações do repositório. Isso é diferente da escrita de arquivos, que funcionou.

O proprietário pode concluir esse ajuste diretamente no GitHub:

1. Abra [Hailton-Reis/Polaris](https://github.com/Hailton-Reis/Polaris) com sua conta.
2. Na coluna **About / Sobre**, use a engrenagem de edição.
3. Use a descrição abaixo e, se desejar, os tópicos sugeridos.
4. Salve os campos. A tarefa não requer alteração de visibilidade nem ativação de GitHub Pages.

## Descrição preparada

```text
Leitor Android de mangás, livros e documentos, com tradução para português, glossário por obra e biblioteca organizada. Candidato a beta interno; armazenamento e validação nos aparelhos em avaliação.
```

## Tópicos sugeridos

```text
android, manga, ebooks, pdf, epub, ocr, translation, pt-br
```

## Site

Não há site separado criado nesta atualização. A apresentação está na página do próprio repositório. O campo de site pode permanecer vazio ou apontar para:

```text
https://github.com/Hailton-Reis/Polaris#readme
```

O repositório permanece privado. Publicar a apresentação ou os APKs para outro público é uma decisão separada dessa personalização.
